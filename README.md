# Countries 🌍

## Небольшое iOS-приложение на Objective-C, созданное для практики разработки под iOS и работы с Objective-C.

### Приложение получает данные о странах через REST API, отображает список стран и позволяет открыть подробную информацию о каждой стране. Для каждой страны также отображается её местоположение на карте с помощью MapKit.
---

## ✨ Возможности: 
- 🌍 Список стран
- 🔎 Поиск и фильтрация
- 📖 Детальная информация о стране
- ⭐ Избранные страны
- 🗺️ Отображение страны на карте
- 🌙 Поддержка Dark Mode
- 💾 Кеширование данных
  
## 🛠 Стек:
- Objective-C
- UIKit
- MVC
- Auto Layout / Constraints
- URLSession
- Codable
- MapKit
- iOS 12.0+

---
### Проект создан в первую очередь для практики Objective-C, работы с UIKit, сетевыми запросами, JSON-декодированием, MapKit и архитектурой MVC.
